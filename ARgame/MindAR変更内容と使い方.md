# MindARへの変更内容と使い方

更新日：2026年10月1日

## 何を変えたか

黒枠付きのHiroマーカーを読むAR.jsから、バラの画像を読むMindAR 1.2.5へ変更しました。

- `targets.mind` は、画像の特徴をまとめた「認識用データ」です。
- カメラに映すのは「缶バッチにする画像.png」の絵です。`.mind` ファイルそのものを撮るわけではありません。
- 今回のデータには画像が1枚入っているため、画像番号は `0` です。番号は0から数えます。

ゲームの会話と3回の発見、花びらの数・色・動き、内外カメラ切り替え、写真の1027×1180サイズとフレームは維持しています。スキャン枠は追加していません。

## 変更したファイル

| ファイル | 役割・変更点 |
|---|---|
| `index.html` | AR.jsの読み込みを外しました。 |
| `ar-effects.js` | MindARで画像を探し、見つけた位置に花びらを出します。 |
| `media.js` | 認識処理が失敗した場合の停止と再試行案内を加えました。 |
| `assets/` | MindAR本体、必要な2ファイル、ライセンスを追加しました。 |
| `marker.html` | カメラに映すバラの画像を表示します。 |
| `tests/browser.html` | Hiroの代わりに、今回の画像で認識を試験します。 |

変更前の主要ファイルは `backup/pre-mindar-20261001/` にあります。古いAR.jsのファイルは残していますが、現在のゲームでは読み込みません。

## 動かし方

1. `README.md` の方法でWebサーバーから開きます。スマートフォンではHTTPSのURLを使います。
2. 別の画面で `marker.html` を開くか、元画像を印刷します。
3. ゲームの「ARを開始」を押し、カメラを許可します。
4. 画像全体を映します。初回は認識の準備に時間がかかることがあります。
5. 認識するとピンクの花びらが舞います。画像を外すと消え、戻すと再開します。

配信時は `targets.mind` と `assets/` 内のMindAR関連ファイルも必要です。元画像は認識処理そのものには不要ですが、`marker.html` を使う場合に必要です。

## 認識する絵を変えるには

1. 作業前にフォルダ全体をコピーします。
2. 新しい絵からMindAR用の認識データを作ります。
3. 新しいデータを `targets.mind` として置き換えます。拡張子だけを変更しても認識データにはなりません。
4. `marker.html` の画像も、新しい元画像へ変更します。
5. ページを再読み込みし、新しい絵で試します。

登録画像が1枚なら `ar-effects.js` の `targetIndex: 0` はそのままです。複数登録した場合は、登録順に0、1、2となります。ファイル名を変えた場合は `imageTargetSrc` も変更します。

```js
imageTargetSrc: 'targets.mind',
targetIndex: 0,
```

**印刷する絵と、データを作る元画像をそろえてください。** 透明な部分の背景色、丸く切り抜く範囲、大きな文字の追加が違うと読み取りにくくなる場合があります。今回の元画像には透明部分があり、`targets.mind` 内では黒背景になっています。黒背景のテスト映像では認識できましたが、白背景では追跡が安定しませんでした。`marker.html` は黒背景で表示します。**白背景で印刷する場合は、白背景にした印刷画像から `targets.mind` を作り直してください。** 実際の缶バッジの背景色と切り抜き範囲で、必ず確認してください。

## スマートフォンで確認してほしいこと

- [ ] 元画像を映すと花びらが出る。関係ない絵では出ない。
- [ ] 絵を外すと花びらが消え、戻すとまた出る。
- [ ] 距離・角度・明るさを変えても、使う予定の場所で認識できる。
- [ ] 紙だけでなく実物の缶バッジでも試す。光の反射や丸い縁で読み取りが止まらないか確認する。
- [ ] ARを停止・再開しても、カメラが二重に動かない。
- [ ] 3回発見して写真画面へ進むと、ARの花びらが止まる。
- [ ] 内外カメラを切り替え、両方で写真を保存できる。フレーム・写真サイズ・鏡向きが以前と同じ。
- [ ] 別のアプリへ移って戻った後、ボタンで再開できる。

問題があれば「端末名／OS／ブラウザ／操作手順／実際の結果」をメモしてください。PCのテスト映像で通っても、スマートフォンの実機確認は別途必要です。

## 少し詳しい仕組み

カメラの開始・停止は、これまでの `CameraSession` が担当します。MindARの `Controller` には、そのカメラ映像を渡します。MindAR側でも別のカメラを起動する仕組みを追加すると、撮影機能と競合するため注意してください。

認識処理は1回ずつ順番に実行し、停止後に古い処理の結果が届いてもARが復活しないようにしています。花びらは毎秒12枚、最大48枚、1枚の寿命は3.2秒のままです。
