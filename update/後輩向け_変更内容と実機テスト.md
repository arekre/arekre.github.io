# ローザのゲーム：変更内容と動作確認のお願い

作成日：2026年9月27日

ver1.3をもとに、カメラや花びらの機能を追加しました。この資料では、変えたところと、スマートフォンで確認してほしいことを説明します。

**現在は試作版です。パソコン上のテスト映像では確認できていますが、実際のスマートフォンのカメラでは、まだ確認できていません。**

## 1. 何を変更したか

- **写真の見え方をそろえました。** 撮影前の画面と保存する写真で、人物の位置やフレームの形がずれないようにしました。
- **準備ができるまで撮影できないようにしました。** 映像やフレームが読み込まれていない状態で、写真を作ってしまうことを防ぎます。
- **カメラを使えないときの案内を追加しました。** エラーの説明を表示し、「再試行」でやり直せるようにしました。
- **使い終わったカメラを停止するようにしました。** 撮影終了時や、別のタブ・アプリに移ったときに停止します。戻った後は、ボタンを押して再開します。
- **会話とゲームの進み方を直しました。** 最初の説明は読み終えてから進められます。次の探索に移ったら、前の会話を消します。
- **ローザの読み込みを待つようにしました。** 読み込めないときは説明を表示し、代わりのキャラクターを出す処理も追加しました。
- **写真画面ではゲームの3D処理を止めるようにしました。** 写真撮影中の余分な処理を減らします。

## 2. 何を追加したか

### マーカーを見つける機能

「マーカー」とは、カメラが目印として読み取る絵のことです。今回は、黒い四角の中に「Hiro」と書かれた**動作確認用のマーカー**を使っています。

ゲーム中に「ARを開始」を押すと、カメラを使えるようになります。ARは、カメラに映る景色へ絵や演出を重ねる機能です。

**今の設定では、バラの画像や実物の缶バッジをかざしても反応しません。** 缶バッジへの対応は、使う画像や大きさを確認してから行います。

### ピンクの花びらが舞う演出

Hiroマーカーが見える間、その位置から花びらが広がります。マーカーを隠すと花びらが消え、もう一度見せると再開します。

花びらの色や形は、添付画像を参考に作った仮のものです。**原画を切り抜いた素材ではありません。** 枚数・速さ・広がり方は、見てもらった後に調整できます。ローザ自身は、これまでのゲーム内の位置に表示されます。

### 写真撮影時のカメラ切り替え

写真画面の右上で、次の2つを切り替えられます。

- **インカメラ**：自分を撮る側。鏡のように左右を反転し、その見え方で保存します。
- **アウトカメラ**：背面側。左右を反転せず、そのまま保存します。

切り替え先が使えないときは、元のカメラに戻す処理を入れています。

## 3. テストの前に用意してほしいもの

1. インターネットにつながるスマートフォン。できればiPhoneとAndroidを各1台。
2. 改修版を開くための、`https://`で始まるURL。**公開作業はまだ行っていないため、URLは別途用意する必要があります。**
3. 印刷したHiroマーカー、またはマーカーを表示する別のスマートフォン・パソコン。

マーカーの画像は `assets/hiro.png` です。`marker.html` にも説明があります。黒枠や外側の白い余白を切り落とさずに使ってください。

ゲームとマーカーは、別々の画面で開いてください。同じスマートフォンの画面に表示したマーカーを、そのスマートフォンのカメラで読むことはできません。

ファイルをスマートフォンで直接開く方法ではなく、用意したURLから開いてください。配信するファイルやパソコンでの起動手順は、同じフォルダの `README.md` にあります。

## 4. スマートフォンで試してほしいこと

チェック欄には、確認できたものだけ印を付けてください。うまくいかなかったものと、まだ試していないものは、後ろの記入欄に残してください。

### A. ゲームを最後まで遊べるか

- [ ] 最初の「tap」を押すと、準備が終わってローザが表示される。
- [ ] 会話のボタンを押すと、自分のペースで説明を読み進められる。
- [ ] 画面を指でドラッグしてローザを探し、タップすると発見した数が増える。
- [ ] 次の探索では、前の会話が画面に残らない。
- [ ] 3回発見すると写真画面へ進む。

### B. マーカーと花びらが反応するか

ゲーム中に「ARを開始」を押し、カメラの使用を許可してください。まずは明るい室内で、黒枠全体を映します。

- [ ] カメラの映像が表示される。
- [ ] Hiroマーカーをかざすと、ピンクの花びらが出る。
- [ ] マーカーをゆっくり動かすと、花びらが出る位置もついてくる。
- [ ] マーカーを隠すと花びらが消え、もう一度見せると再開する。
- [ ] 花びらの表示中も、ローザを探してタップできる。
- [ ] 「ARを停止」を押すとカメラが止まり、もう一度開始できる。

続けて、少し近づける・遠ざける・傾ける・明るさを変える、を試してください。反応しにくい条件は、大体の距離や場所もメモしてください。距離の合格基準はまだ決めていません。

### C. カメラを切り替えて写真を保存できるか

- [ ] 写真画面で自分側のカメラが映る。準備中は撮影ボタンを押せない。
- [ ] 「アウトカメラへ」で背面に切り替わり、「インカメラへ」で戻る。これを3回ほど繰り返しても止まらない。
- [ ] 両方のカメラで写真を撮り、撮影結果を表示できる。
- [ ] 撮影前と撮影後で、人物の位置やフレームの形が大きく変わらない。
- [ ] 文字の書かれた紙を撮ると、インカメラは鏡のように反転し、アウトカメラは普通に読める。撮影前後で向きが一致する。
- [ ] 「写真を保存」または画像の長押しで保存し、端末に保存された画像を開ける。保存先はブラウザによって異なる。
- [ ] 「もどる」で撮影画面に戻り、もう一度撮影できる。
- [ ] 「撮影を終了」で映像が止まり、少し待つと端末のカメラ使用中表示も消える。

### D. 困った場面から戻れるか

- [ ] カメラの使用を一度拒否すると、理由が画面に出る。写真画面では撮影できない状態になる。
- [ ] ブラウザの設定でカメラを許可し直した後、「ARを開始」または「再試行」で再開できる。ページの開き直しが必要だった場合は、そのことも記録する。
- [ ] 別のアプリに移るとカメラが止まり、ゲームに戻ってボタンを押すと再開できる。
- [ ] 画面を縦・横に回しても、ボタンが隠れたり、写真のフレームや花びらの位置が大きくずれたりしない。
- [ ] 数分遊んでも、操作できないほど遅くなったり、画面が固まったりしない。

カメラが1台だけの端末もあれば、切り替えボタンを押しても使える状態に戻るか確認してください。手元にない端末のテストは「未実施」で構いません。

「動かない」だけでなく、**何をしたときに、どうなったか**が分かると直しやすくなります。次をコピーして記入してください。


記入例：「iPhoneのSafariで、写真画面の『アウトカメラへ』を押すと映像が黒くなる。3回試して3回とも同じ。『再試行』で戻った。」

## 6. 仕上げるために教えてほしいこと

- 本番で使う缶バッジの画像と大きさ。画像の周りに黒い枠を付けてもよいか。
- 花びらは、かざしている間ずっと出すか、1回だけ出すか。マーカーを隠したらすぐ消してよいか。
- 花びらの色・数・速さがイメージに合っているか。原画を使うなら、赤い線がない画像と、使いたい部分。
- 本番で使うスマートフォンと、公開する場所。
